# 內埔裝車助手・電腦版

開啟 GitHub Pages 網址即可使用。不需要 GPT 帳號。出貨單儲存在這台電腦的瀏覽器；請定期匯出備份。

index.html 是可直接執行的完整網頁。source.zip 為原始程式與建置說明。

舊 Sites 雲端出貨單尚未轉入本版，請另外保留。備份檔包含出貨資料，不要上傳到公開儲存庫。

## 中文功能與操作說明

[開啟裝車助手](https://sq087786789-lgtm.github.io/neipu-cargo-desktop/)；[操作說明與 AI 重建入口](https://sq087786789-lgtm.github.io/neipu-cargo-desktop/ai.html)。可設定車斗、新增貨物、調整立體排列與堆疊，並使用棧板方格輔助規劃。本機出貨單以 JSON 匯出／匯入跨裝置移交。
